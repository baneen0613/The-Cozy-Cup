
# The Cozy Cup — Café & Coffee Website

The Cozy Cup is a responsive café website where visitors can explore a small menu of coffee, tea, desserts, and snacks. It was created as a beginner-friendly front-end project to practise building a welcoming website with HTML, CSS, and JavaScript.

## Technologies Used

- HTML5 — page structure and content
- CSS3 — layout, colors, styling, and responsive design
- JavaScript — menu search, category filters, and mobile navigation

## How to Run

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and `script.js` in the same folder.
3. Open `index.html` in a web browser.
4. Use the category buttons to filter menu items.
5. Type in the search box to find a menu item.

An internet connection is needed for the Google Fonts and menu photographs.

## Features

- Responsive layout for desktop, tablet, and mobile
- Café introduction and story sections
- Menu cards with descriptions, categories, and sample prices
- Menu category filters and live search
- Mobile navigation menu
- Café location, opening hours, and contact section

## Project Files

- `index.html` — website content and structure
- `style.css` — design and responsive layout
- `script.js` — menu data and interactive features
- `README.md` — project information and instructions
